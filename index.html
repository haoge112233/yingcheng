📋 使用说明

情况1：手机和电脑在同一WiFi

  1. 在Termux启动服务器：python server.py
  2. 获取手机IP：ifconfig | grep inet
  3. 电脑访问：http://[手机IP]:8088

情况2：需要公网访问

  1. 安装ngrok：pkg install wget && wget [ngrok下载链接]
  2. 启动ngrok：./ngrok http 8088
  3. 使用ngrok提供的地址
